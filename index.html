☁️ Sync Setup — Firebase

Sync orders between your laptop and mobile using a free Firebase Realtime Database. Set it up once on the laptop, then enter the same Database URL and Sync Code on your mobile.

First time? Click here for setup steps (3 minutes)
  1. Open console.firebase.google.com and sign in with a Google account.
  2. Click Add project → name it julphar-portal → Continue. Disable Google Analytics if prompted → Create project.
  3. In the left menu pick Build → Realtime Database → Create Database.
  4. Pick a location (e.g. europe-west1) → choose Start in test mode → Enable.
  5. Copy the URL shown at the top of the database (looks like https://julphar-portal-default-rtdb.europe-west1.firebasedatabase.app) and paste it below.
  6. Pick any short Sync Code (e.g. amr-2026). On your mobile, paste the same URL and Sync Code here.
After 30 days Firebase locks test rules. To keep working, in Firebase Console go to Realtime Database → Rules and set both .read and .write to true, then Publish.
